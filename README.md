# Software Portfolio Showcase & Admin Panel

Aplikasi web portofolio e-commerce interaktif untuk memamerkan katalog produk software, aplikasi enterprise, dan platform SaaS yang telah dirilis maupun dalam roadmap pengembangan.

## 🔗 Akses Cepat
- **Public Showcase:** [http://localhost:8080/software-showcase/](http://localhost:8080/software-showcase/)
- **Admin Panel:** [http://localhost:8080/software-showcase/admin/](http://localhost:8080/software-showcase/admin/)
  - *Password Admin Default:* `nexus2024`
